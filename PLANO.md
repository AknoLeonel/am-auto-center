# Plano de construção: AM Auto Center

App mobile-first (PWA) para a oficina, com site público otimizado para SEO.

| Fase | Foco | Status |
|---|---|---|
| 0 | Fundação: auth por cookies + proxy, migrations, RLS e papéis, UI base, CI | Concluída |
| 1 | Núcleo rápido: Server Components/Actions, busca paginada no servidor, criação de OS transacional, fotos, Kanban | Concluída |
| 2 | Operação: orçamento digital com aprovação por link, checklist, estoque, agenda, garantia, PDF | Pronta, aguardando PR |
| 3 | Dados: auditoria, histórico de status, dashboard financeiro, relatórios e exportação | Pendente |
| 4 | PWA completo: offline com fila, Realtime, push, acompanhamento pelo cliente | Pendente |
| 5 | SEO: páginas por serviço/cidade, schema, Core Web Vitals, Google Business | Pendente |
| 6 | Qualidade: testes unitários e e2e, Lighthouse CI, Sentry, backups | Contínuo |
